# 3.51 客户端问题回归记录

修复阶段未修改完整包或 `assets/` 源文件；本次发布包含用户另行更新的 HD／PTR 着色器。真实魔兽目录仅用于只读 CASC 预览；所有文件安装、开关、删除和更新测试均使用临时目录。发布验证另见下方记录。

## 已处理的问题

- 安装器遇到 `resources/app.asar`：原来会将客户端文件当资源文件处理，Electron 随后报含糊的 `Invalid package`。现在选错客户端 ZIP 或文件夹会在目标目录写入前明确提示应选择 QMF 资源包，不要求资源包与清单完全相同。
- 增加已解压文件夹的安装入口；原单 ZIP 和独立 A/B ZIP 入口保留。复制实际文件，源目录和目标中的额外玩家文件不删除。
- MOD 开关的旧搬运记录可能包含已被画质配置移除的 DNC 文件。启用和恢复时跳过不存在的项，仍处理实际存在的资源，不以缺少一项阻止 MOD 开启。
- 安装新包前先恢复该分支的旧开关记录，避免旧 `QMoff` 文件在新包复制后覆盖新资源。
- 手动下载入口统一指向 `https://qm.txzy.net`，不再指向失效的玩家页路径。
- 自定义皮肤增加删除接口和确认按钮；已选择该皮肤的配置恢复原版，关闭的皮肤配置保持关闭。外部导入只清理导入副本，不删除来源模型或游戏路径模型。
- SD 原版预览从基础 CASC 图层读取，CASC 模型贴图沿用模型图层，不混用目录中的 HD 覆盖；外部导入模型仍读取自己的贴图。
- 外部皮肤导入后的白膜路径问题：原导入器只复制贴图而不改模型引用。现在按现有 COS 模型的原则，将导入贴图路径写为相对所选游戏分支资源根目录的 `cos\custom\...\textures\...`，使用实际贴图扩展名；同名不同目录不混配，普通和 HD 模型各自扫描。MDX 仅原位修改 TEXS 的固定路径字段，其他区块及动画不重写；MDL 仅修改 Bitmap 的 Image。替换贴图和确认可用的游戏公共贴图保留原引用。旧客户端已导入副本在列出／应用皮肤时按已有贴图修复，原始文件不改。
- 四族主基地、人类防御塔／炮塔／神秘塔、不死幽魂塔／蛛网怪塔按实际单位选择 `Stand Upgrade First/Second/Third`，而不是共用第一段 `Stand`。对应单位和动画属性已只读核对游戏 UnitFunc 数据。
- 修复从 `QMoff/ui` 恢复时的 `ENOTEMPTY`：旧逻辑把只有空子目录的 UI 判断为空，却用非递归 `rmdir` 删除。按明确的目录管理要求，所选分支的 `ui` 完全由客户端管理；恢复时替换旧 UI，切换风格时先解压并准备客户端 UI 资源，再重置整个 `ui`。此规则不扩展到其他资源目录或另一分支；客户端源资产仍为复制，不移动。
