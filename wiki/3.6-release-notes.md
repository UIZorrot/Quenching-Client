# 淬火 3.6 更新日志

客户端内部版本：3.6.0；MOD 资源版本：3.6。GitHub 便携包和更新产物已正式发布；官网自动更新正在按发布窗口部署、验收。

- 更新支持跨版本直接补齐最终变化文件，无需依次安装每个中间版本。
- 客户端差分不匹配或重建失败时，可下载对应文件的完整版本；改进中文及特殊字符路径兼容。
- 修复更新后部分模块无法加载的问题，并改善下载低速时的备用源切换。
- 完善完整包安装引导，支持文件夹和独立 A／B ZIP，并明确提示选错客户端包。
- 修正 MOD 关闭状态下的资源同步，安装和设置操作保留开关状态及原有偏好。
- 自定义皮肤支持自动检索模型依赖及魔兽自带贴图，并修正导入模型的贴图路径。
- 完善自定义皮肤的肖像关联、正常／禁用图标及删除后的配置恢复。
- 修正 SD 预览资源图层、建筑升级动画和模型部件显示。
- 涂装页面增加“被遗忘的圣骑士”，补齐多语言显示。
- 新配置按系统语言初始化，已有手动选择保留；修复非中文界面的英文更新日志加载。
- 增加内嵌论坛入口，独立保留论坛登录会话。
- 魔兽 3.0 及以上增加战网启动与战役解锁流程；不可用时保留直接启动。
- 更新地形、悬崖和透明水基础表，补齐新版记录并保留淬火路径；非透明水使用游戏原生颜色参数。
- 更新树木／可破坏物基础表，区分旧版与 3.0 配置，并保留树木预设。
- 同步着色器资源，Retail HD 战斗光照使用对应 melee 着色器。
- 修正 DE 切回 HD 后地形／水面选项锁定及界面状态不同步的问题。
- 感谢新贡献者 Dariusz Sikorski（dariuszsikorski）的翻译与战网启动思路贡献。

## 发布边界

Windows 3.5.0／3.5.1 兼容引导已完成本地候选端到端验收，正式网站升级另验收；macOS 继续手动换包。本次 MOD 使用 GitHub Release 与客户端低速镜像，不启用失败的 GitLawb MOD 或尚未验收的新协议 R2。客户端 GitLawb 源已上传并核验。

首装完整3.5 A/B包继续保留；新增普通 `QMF3.5-to-3.6.zip`，约33 MiB，覆盖原3.5完整资源升级。已安装用户可直接确认自动更新，无需重新下载完整版。差异ZIP不是完整包或客户端，包内说明列出覆盖位置与唯一退役旧文件的处理方法。
