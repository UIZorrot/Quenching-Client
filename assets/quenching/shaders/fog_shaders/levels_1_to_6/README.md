# 天空雾恢复：亮度 1～6 测试包

天空覆盖开关默认打开：SKY_FOG_EXTEND=True，SKY_RESPECT_MAP=False。
线性雾天空覆盖80%，指数雾和高度雾75%；使用地图雾颜色。
天空覆盖不乘整体减雾倍率。普通雾仍响应地图 fade，地图 fade=0 时天空也透明。
无 fog 的 chunk 0/4 保留原有薄雾；不增加75%/80%的天空遮蔽。

AO半径80；亮度1/2/3强度0.80，4为0.68，5为0.56，6为0.44。
退出游戏，备份当前两个fog文件，把 brightness_N/ps/ 中的
fog.bls 与 volumetricfog.bls 复制到游戏 shaders/ps/，再重新启动。

本次仅导出，未部署。所有启用fog的模式测试了32768/40000/1000000深度、
地图天空开关和fade；合成及AO递减检查通过。实际观感仍需游戏确认。
